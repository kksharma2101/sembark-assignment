# E-Commerce Web App

A modern, fully responsive e-commerce web application built with React and TypeScript, featuring state management via Context API, routing with React Router DOM, and styling with Tailwind CSS.

## Features

- Product listing and filtering
- Fully responsive design
- Shopping cart management
- Order management
- Modern UI with Tailwind CSS
- Persistent cart state across page refreshes
- filtered/sorted product 

## Tech Stack

- **Frontend Framework**: npx create-react-app folder_name --template typescript
- **Language**: TypeScript
- **State Management**: Context API
- **Routing**: npm install react-router-dom
- **Styling**: Tailwind CSS
- **Icons**: React Icons (npm install lucide-react@next)
- **HTTP Client**: Axios (npm install axios)

## Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** 
- **npm**
- **Git** (for cloning the repository)
